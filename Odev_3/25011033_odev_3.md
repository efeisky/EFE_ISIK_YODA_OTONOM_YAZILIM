### Veri Türleri

```
string
int, float, complex
list, tuple, range
dict
set, frozenset
bool
bytes, bytearray, memoryview
NoneType
```
**string**: Metinsel ifadeler için kullanılan veri türüdür.  
**int**: Tam sayılar için kullanılan türdür.  
**float**: Ondalıklı sayılar için kullanılır.  
**complex**: Karmaşık sayılar için kullanılır.  
**list**: Array oluşturmak için kullanılır.  
**tuple**: İmmutable(değişmez) veriler için kullanılır.  
**range**: Sayı aralığı üretimi için kullanılır.  
**dict**: Sözlük olarak çevrilir. Belirli değere karşılık değer için kullanılır._(key-value)_
`myDict={"name":"Fehmi", "age": 34}`  
**set**:  Küme işlemleri için uygun bir türdür. Mutable(değiştirilebilir) veri saklar ve hashlenemz.  
**frozenset**: Set gibi küme için uygundur ancak immutable ve hashlenebilirdir.  
**bool**: True | False gibi durumlar için oldukça kullanışlı bir türdür.  
**bytes**: İçeriği değiştirilemez bayt dizisi türüdür. Salt okunurdur.  
**bytearray**: İçeriği değiştirilebilir veridir. Ekleme, silme, güncelleme için uygundur.  
**memoryview**: Veriyi kopyalamadan doğrudan bellek erişimi ile erişmek için kullanılan bir türdür. Buffer protokol destekleyen nesnelerde kullanılır.Bellek üzerinde veri manipülasyonu yapma imkanı sunar. Büyük verilerde kullanılır.  
Son olarak NoneType ise boş veridir.  
Python dilinde veri türleri değişkeni tanımlarken ifade edilmez dinamik olarak program tarafından ayarlanır. Bu yüzden değişken yazarken veri türlerini yazmaya gerek yoktur.

### İf-Elif-Else
```
if z>y:
    print(...)
elif z==y:
    print(...)
else:
    print(...)
```
Python if-elif-else syntaxı yukarıdaki gibidir. Koşul ifadeleri için kullanılır. if ya da elif bloğunda True sonucu çıkarsa o bloğa girer. Elif ve else blokları zorunlu değildir. Eğer gerekli değilse konulmaz ve blok sonrasında tekrar program aynı düzeydeki ifadeden devam eder.

### For-While
```
for i in range(1, 10):
    print(i)
```
For döngüsü ifadesi belirli bir dizide veya sayı rangeinde döngü ile her değerin alınmasını sağlar. Yukarıda 1 den 10'a kadar sayılar ekrana yazdırılmak üzere bir kod verilmiştir.
```
while a<3:
    print(a)
    a+=1
```
Yukarıda while için de bir kod bloğu örneği verilmiştir. a'3ten küçük olduğu sürece while bloğu çalışacaktır. `continue` ve `break` ifadeleri de bulunur. Bu ifadeler ile blokta akış süreci yönetimi sağlanır. Gereken akış atlanabilir ya da bitirilebilir.

### Fonksiyonlar

```
def sum(a, b):
    return a+b
```

Fonksiyonlar void veya returnlu olabilir. Herhangi bir veri türünde veri döndürebilirler. Fonksiyon tanımlarken def ifadesi kullanılır sonrasında fonksiyon adı ve değişkenler bulunur. Fonksiyon içinde tanımlanan değişkenler fonksiyon bloğu içinde kalır ve dışarıdan erişilemez. Dışarıdan ise aşağıdaki şekilde çağırılırlar.

```
a=3
b=2
s = sum(a, b)
print(s)
```

### Sınıf(Class)

```
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def print_infos(self):
        print(self.name)
        print(self.age)

kisi = Person("Efe", 19)
kisi.print_infos()
```

Class ifadeleri yukarıdaki örnekteki gibi kullanılırlar. Aslında belirli nesneleri tanımlamak için onları alt özellikleriyle beraber tek bir ifade olarak tanımlamamızdır. Yukarıda bir insanın 2 temel özelliği olan isim ve yaşı üzerinden bir örnek yapılmıştır. self.___ herhangi bir veri türünde olabilir. 

```
self.tckn  -> Public değişken(dışarıdan erişilebilir)
self.__tckn -> Private değişken(dışarıdan erişilemez)
```
